# 2026-08-29 派單防誤判規則

本修正針對 08/27 真實派單曾被誤算為 14點834件／85,400元。

## 根因
1. 純地址行 `台南市東區崇學路271-10號` 中的 `271` 被 implicit quantity parser 誤當件數。
2. `1100南轉南配🔺劉育成03` 中的尾碼 `03` 有被誤當件數風險。
3. `台南*南集貨站` 同一實體集貨點重複三筆，未固定化時會被拆成多點。
4. `南轉南配` 區段應獨立於一般花市點件計價；正式 08/27 案例為 4件×50=200，行首明寫 1100 為特別勤務加給。

## 新規則
- 純地址輔助行不進 implicit quantity parser。
- `南轉南配` 到分隔線之間的派單獨立計件，不納入一般點數／件數與 PT 打底。
- `台南*南集貨站`／`台南南集貨站` 固定對應 `台南市東區崇學路271-10號`，同址合併1點。
- 08/27 正式回歸：一般花市 5點14件=1900；PT台南打底800；南轉南4件=200；特別勤務1100；總計4000。
- 先前新增的日結驗算路由保持優先，不回歸。
